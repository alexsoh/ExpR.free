# ExpR.free - ExpirationReminder (Free APK Release)

Official APK release distribution repository for **ExpirationReminder**.

## Download & Installation

1. **Download APK**: Download [`ExpirationReminder.apk`](https://github.com/alexsoh/ExpR.free/raw/main/ExpirationReminder.apk) or grab the latest binary from the [Releases Page](https://github.com/alexsoh/ExpR.free/releases).
2. **Install on Android**:
   ```bash
   adb install -r ExpirationReminder.apk
   ```

## Features Included
- On-device Google ML Kit Text Recognition (100% offline, private OCR).
- Multi-date candidate detection & interactive selection modal (`MM/DD/YYYY`, `DD/MM/YYYY`, `YYYY-MM-DD`, `MM/YY`).
- Category Tag Organization (`Driver License`, `Passport`, `State ID`, `Work ID`, etc.).
- WorkManager background local expiration reminder alerts with configurable lead times (60, 30, 14, 7 days).
- Google Drive & Local ZIP Backup / Restore engine with unique timestamp deduplication.
- Executive Bluish-Gray Slate design theme & high-contrast UI.
- Google AdMob Adaptive Banner & Interstitial Ads monetization.
